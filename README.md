# CYBERDECK

Live-дистрибутив на базе Arch Linux с интерфейсом в стиле киберпанка.

ISO собирается автоматически в GitHub Actions: вкладка **Actions** → **Build CYBERDECK ISO** → **Run workflow**.
Готовый файл появится внизу страницы запуска в разделе **Artifacts** (`cyberdeck-iso`).

Логин и пароль в live-системе: `cyber` / `cyber`.
